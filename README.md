# FlagSwitch

Мгновенное переключение раскладки клавишей Globe и плоские флаги стран в строке меню macOS.

**[⬇ Скачать FlagSwitch (.dmg)](https://github.com/Emileminov/FlagSwitch/releases/latest/download/FlagSwitch.dmg)** - откройте .dmg и перетащите FlagSwitch в «Программы». Подписано Developer ID и нотаризовано Apple. Нужна macOS 13 или новее.

## Что умеет

- Клавиша Globe переключает раскладку сразу, без системной анимации
- В строке меню вместо двух букв - плоский флаг страны
- Раскладки подхватываются из системы сами
- Автозапуск при входе в систему

В системных окнах открытия и сохранения файлов раскладка переключается обычным способом - это ограничение macOS.
